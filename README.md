# Henrica Construction

Marketing site and client portal preview for **Henrica Construction SARL** (Kinshasa, DRC).

**Live preview:** https://here2serveu.github.io/henrica-construction/

## What's included

- Single-page marketing site with **French / English** language toggle
- Services, completed projects, why-us, and contact sections
- **Quote request** modal with form validation
- Mock **client login** that opens a dashboard with:
  - Projects tab — milestones and progress
  - Invoices tab — billing summary
  - Documents tab — contracts, plans, permits
  - Messages tab — direct messaging with the team
- Fully **mobile-responsive** layout with hamburger menu

## Notes

This is a design and flow preview meant to be reviewed before final copy, photos, and integrations are added. The login (`demo@henrica.cd` / `demo123`) and quote form are in demo mode — submissions are captured visually but not sent anywhere yet.
